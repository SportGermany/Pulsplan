# Pulsplan

Atem- und Pulstraining als Web-App. Läuft im Browser, lässt sich als App installieren
(Chrome: Menü ⋮ → **App installieren**) und funktioniert nach dem ersten Öffnen offline.
Teil des SportGermany-Verbunds: gemeinsamer Kalender, App-Wechsel und Cloud-Sync über den Knopf unten rechts.

Veröffentlichen: **Settings → Pages → Deploy from a branch → main / (root)**.
Danach erreichbar unter `https://sportgermany.github.io/Pulsplan/`.
